# NOIR — Fashion Landing Page

A bold editorial fashion landing page built with HTML, CSS and JavaScript.

NOIR explores the intersection of **fashion, typography and modern frontend development**, with a strong focus on visual hierarchy, responsive design and immersive user experience.

## ✨ Features

- Responsive desktop and mobile design
- Bold editorial hero section
- Fashion-focused UI/UX
- Interactive navigation
- Mobile navigation experience
- Smooth scrolling
- Scroll-based animations
- Product and collection presentation
- Strong typography and visual hierarchy
- Modern responsive layouts

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design

## 🎯 Project Goal

NOIR was created as a portfolio project to demonstrate my ability to transform a strong visual direction into a functional and responsive frontend experience.

The project focuses on combining **editorial fashion design with modern web development**, creating an experience that feels closer to a real fashion brand than a traditional landing page.
